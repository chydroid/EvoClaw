=== EcoClaw 入门引导 ===

1. 启动服务器: node apps/server/dist/index.js
2. 打开仪表盘: ecoclaw dashboard
3. 配置 LLM:  打开 Web UI → LLM 标签 → 填入 API Key
4. 安装 Skills: ecoclaw skills install <slug>
5. 配置频道:  打开 Web UI → Channels 标签

✅ 入门引导完成！跟着上面 5 步即可开始使用。
