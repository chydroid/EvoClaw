# 邮件工具技能 (Email Tool)

## 名称
email-tool

## 描述
快速发送邮件、查看收件箱、管理多个邮箱账户的邮件助手技能。

## 版本
1.0.0

## 功能
1. **发送邮件** — 通过已配置的邮箱账户发送邮件
2. **查看收件箱** — 浏览最近未读邮件
3. **收件箱摘要** — 生成收件箱摘要报告
4. **多账户管理** — 支持 QQ、163、Gmail、Outlook 等多个邮箱

## 使用方法
主人可以直接对我说：
- "发邮件给 xxx@xxx.com，主题是...，内容是..."
- "看看我的收件箱"
- "帮我配置一个新的邮箱"

## 配置邮箱
使用 `email_add_account` 工具配置邮箱账户，需要提供：
- 邮箱地址
- 密码（QQ/163邮箱需使用授权码）
- 邮箱提供商（qq / 163 / gmail / outlook）
- 显示名称
